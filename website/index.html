Great Display menu

Features

Everything your displays can do.
Without opening System Settings.

Brightness that goes further.

Native panel brightness on Apple displays, DDC/CI on external monitors and gamma dimming everywhere, combined into one knob. Brightness keys work on every display, with a glass on-screen display.

Resolutions and HiDPI

A resolution slider with Default and Native markers, a mode list filtered by density, refresh rate and aspect ratio, and a strict HiDPI toggle that keeps the refresh rate.

Virtual screens

Any aspect ratio, about 40 sizes each, live resizing and an optional 16K ceiling. Associate them with real displays to auto-connect, mirror, stream or follow rotation.

DDC/CI device control

Contrast, volume and mute, input source, picture modes, colour presets, RGB gain, sharpness and standby, read from your monitor's own capabilities. Raw VCP access for the curious.

Streaming

Stream any display full-screen onto another, or onto itself, with crop, flip, rotation, zoom, underscan and integer scaling. Interactive mode lets you use the stream like a normal screen.

Mirroring and arrangement

Mirror, choose the main display, rotate to 0°, 90°, 180° or 270°, toggle HDR, and connect or disconnect a display without unplugging it.

Colour and comfort

Dark Mode, Night Shift and True Tone toggles, per-display gamma, colour temperature, contrast and RGB gain, plus Prevent Sleep for presentations.

Scriptable

The app doubles as a command line tool, and greatdisplay:// links open settings or a display from Shortcuts, scripts or a browser.

For power users

Script every pixel.

The executable inside the app bundle is also a command line tool for automation and diagnostics.

  • --probe prints every display, mode and capability as JSON
  • --set-resolution, --rotate, --mirror and --hdr
  • --ddc-read, --ddc-write and --ddc-caps for monitors
  • greatdisplay://settings, /display/<id> and /brighten

Install

          
Up and running in a minute.

        

        

          
Download
Get the latest GreatDisplay-1.0.0.dmg from the Releases page.

          
Drag to Applications
Open the disk image and drag Great Display into Applications. It's universal, for Apple silicon and Intel.

          
Find it in the menu bar
Launch it and click the display icon in the menu bar. There's no Dock icon. Option-click opens Settings.

        

        

          
First launch. Release builds are not notarized by Apple yet, so macOS blocks the first launch. Open System Settings › Privacy & Security and click Open Anyway, or remove the quarantine flag in Terminal:

          
xattr -dr com.apple.quarantine /Applications/GreatDisplay.app

          
Accessibility access enables the brightness and volume keys; Screen Recording is only needed for streaming. Everything else works without extra permissions.
